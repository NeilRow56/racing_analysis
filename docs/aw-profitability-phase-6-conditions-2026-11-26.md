## Three fixed development rules

- **A · V1 abstention in sprint handicaps.** At any AW course, if the pre-off card confirms a handicap and recorded yardage is **990–1,429** in the established 5–6f band, record NO BET. Otherwise retain unchanged V1, including its own abstentions. A missing, ambiguous or inconsistent trip or handicap flag keeps V1.
- **B · T2 in sprint handicaps.** Same verified trigger as A, but use original T2 on every trigger, including where V1 would abstain. Otherwise use V1.
- **C · T2 at 10–12f.** Use original T2 when verified yardage is **2,090 to under 2,750**. Otherwise use V1. Handicap status does not enter this rule.

The three rules use the same original ranks and full race populations. The trigger fields must exist before off and agree with the exact captured card. No rule uses prices to choose, changes an individual selection after a result, or reranks the field. Missing prices affect only the quoted evaluation. The boundaries are fixed nominal trip bands. The groups were selected after inspecting the distance and handicap results, so testing a small set of rules still carries selection bias.

## Proposed prospective comparison

Advance **only A** as a testable hypothesis. For any AW race, use the same original Tissue V3 field and V1 decision. Record an additional abstention only if the captured card confirms a handicap and an integer yardage from 990 through 1,429 within the established sprint group. Treat conflicting, ambiguous or absent condition evidence as the original V1 decision. Capture original T2, V1 and challenger decisions, source timestamp, exact yardage, verified handicap, field and price board before the scheduled off. Count canonical settlement, price coverage and late withdrawals on the same opportunity IDs.

Make **paired captured-price £1 P/L versus V1** primary and verified SP secondary, alongside T2 on those same opportunities. Compare the trigger with skipping the same number of V1 bets selected by a fixed seeded draw from other retained V1 handicap bets in the same calendar month and material. Freeze the draw, strata, review timing and matched coverage requirements before looking at any new outcomes. Report differences across courses and date blocks and the cost of missed higher-priced winners. Positive returns from the skipped V1 bets, an incremental result no better than the equal-stake control, a persistent captured/SP reversal, or gains that disappear outside one venue or on removal of one paired race would count against the rule. November already shows how that captured-price reversal can happen.
